# Public Repository Manifest

- `.github/`: public issue, pull-request, and CI configuration
- `apps/`: web, API, documentation, and future public application source
- `crates/`: VibeProof Rust components
- `packages/`: shared TypeScript schemas, protocol bindings, UI, and configuration
- `docs/`: public product, architecture, privacy, security, design, implementation, and QA specifications
- `infrastructure/`: reproducible public deployment examples without private environment values
- `scripts/`: public development and validation tooling
