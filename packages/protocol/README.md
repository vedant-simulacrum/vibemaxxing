# Protocol Bindings

This is the future home of generated cross-language protocol bindings. It is not an implemented package yet.

Authoritative sources currently live in `packages/schemas/`:

- VibeProof claim CDDL;
- local-control and social/integrity Protobuf definitions;
- OpenAPI and JSON Schemas;
- reason-code and policy registries.

Generation begins only after explicit implementation approval and toolchain selection. Generated code must be reproducible and must never become an independent source of protocol semantics.
