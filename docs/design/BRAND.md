# Brand Guidelines

## Canonical name

`vibemaxxing`

Prefer lowercase wordmark presentation.

## Brand character

- Premium
- Competitive
- Technically credible
- Social
- Slightly provocative
- Privacy-conscious
- Calm rather than noisy
- Serious but playful

## Visual thesis

> Codex restraint × Steam social competition

Approximately:

- 70% refined technical product
- 30% competitive social network

## Theme

- Light first
- Warm-neutral background
- White primary surfaces
- Near-black typography
- Electric indigo accent
- Indigo used sparingly

## Wordmark

Begin with a refined wordmark rather than forcing a symbol.

Explore:

- Custom `x`
- Crossing paths
- Overtaking
- Symmetric competition motif

Avoid:

- Coins
- Flames
- Gauges
- Lightning
- Literal tokens
- Code brackets
- Crypto styling
- Esports chrome

## Copy voice

Balanced, concise, premium, mildly internet-native.

Examples:

- `Burn more. Rank higher.`
- `Public competition. Private transcripts.`
- `You were overtaken.`
- `Active in Codex.`

Avoid corporate language and exaggerated security claims.
