# Integrity Model

## Consumer-facing states

### Standard

Live VibeProof collection without elevated OS monitoring.

### Hardened

Optional stronger process, source, and device evidence is enabled.

### Imported

Historical usage loaded from mutable local records. Imported activity is private analytics only and does not affect competitive rankings.

Avoid the word `verified`.

## Evidence dimensions

Internally retain two independent dimensions:

### Capture strength

- Imported
- Live file observed
- Native event
- Protocol bound
- Model-call bound

### Environment strength

- Unmeasured
- Signed node
- Source bound
- Device attested
- Confidential environment

## Ranking policy

- Competitive rankings require live activity.
- Strongest integrity views require live capture, supported adapter, official signed build, source recognition, continuity, semantic checks, and available attestation.
- Unknown source versions fail closed or downgrade.
- Any observation gap breaks hardened continuity.
