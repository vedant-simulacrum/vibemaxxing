# T20 Certification and Selection Specification

Status: normative planning contract
Updated: 2026-07-19
Scope: P-1130A through P-1130D

This specification completes the planning semantics required by the T20 golden-path contract. It defines what is certified, how evidence is trusted, how the rolling cohort is selected, and how accounting sources are reconciled. It does not identify the production T20 cohort or claim implementation
