# Generated Repository Metadata

This directory is reserved for deterministic repository inventory and checksum outputs generated by:

```bash
python3 scripts/repository/generate_repository_metadata.py
```

Generated files:

- `MANIFEST_FILES.txt`
- `FILE_INDEX.md`
- `SHA256SUMS`

These files describe a particular checkout. They are not product, architecture, planning, or implementation authority and must never replace the live Git tree or `docs/project/DOCUMENTATION.md`.
