# vibemaxxing brand assets

Canonical vector assets for product and communications.

- `wordmark.svg`: primary lowercase wordmark on light backgrounds.
- `wordmark-reverse.svg`: wordmark on dark backgrounds.
- `mark.svg`: dark app/avatar mark.
- `mark-light.svg`: light-surface mark.
- `favicon.svg`: small-size browser mark.
- `social-card.svg`: default 1200×630 social preview.

The crossed `x` represents two competitors changing position. The indigo stroke is the overtaking path. Keep clear space around the wordmark equal to the height of its lowercase `v`. Do not recolor individual letters, add gradients, rotate the mark, or pair it with flame, coin, gauge, lightning, token, or code-bracket imagery.

The wordmark SVG retains live text so it can be refined while the identity is still being validated. Convert it to final outlined paths before external trademark or print usage.
