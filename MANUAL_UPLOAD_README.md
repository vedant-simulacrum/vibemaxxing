This folder is the complete, authoritative VibeMaxxing project repository.

Upload the **contents of this folder** to the root of `vedant-simulacrum/vibemaxxing`.
Do not upload an extra enclosing directory level.

Start future work with:

> Read `START_HERE_PROMPT.md`, `CURRENT_STATUS.md`, and `IMPLEMENTATION_ROADMAP.md`. Execute the next highest-priority unblocked task, run all applicable tests and evals, and update status and evidence before stopping.

This package intentionally contains no `.git` directory, bootstrap archive, base64 chunks, or temporary importer workflow.
