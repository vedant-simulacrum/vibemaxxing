# VibeMaxxing

VibeMaxxing is an open-source, privacy-preserving competitive leaderboard and social layer for AI-agent activity. It is built on VibeProof, a local-first accounting and integrity protocol.

## Current development position

Development is local-first. There is no remote development control plane, autonomous cloud bootstrap, remote agent fleet, or infrastructure prerequisite for building the project. Cloud services may be introduced later only where the product itself requires them and after explicit validation.

## Principles

- No prompts, responses, code, diffs, filenames, paths, project names, or transcript content are sent to VibeMaxxing servers.
- Competitive ranking is based on live, source-bound activity claims rather than editable retrospective logs.
- Token Burn and estimated API-equivalent Cash Burn are first-class metrics.
- The protocol, collector, server, web application, schemas, and security model are developed in public.
- Weak evidence never masquerades as strong evidence.
- Prefer a complete tested vertical slice over broad placeholder scaffolding.

## Superseded direction

All previous remote-machine bootstrap, remote orchestration, remote model-routing, remote secret migration, persistent remote worker, and remote source-of-truth plans are cancelled. They must not be reintroduced unless the user explicitly makes a new decision later.
